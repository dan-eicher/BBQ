# BBQ Static C++ Parser Generator Design

A Coco/R-style code generator that compiles `.bbq` format specifications into
standalone C++ parsers. No VM, no interpreter — just generated functions you
compile and link.

## Architecture Overview

```
                        ┌─────────────────┐
  format.bbq ──────────▶│  BBQ Frontend    │
                        │  Parser (pegc)   │
                        └────────┬─────────┘
                                 │ BBQ AST
                        ┌────────▼─────────┐
                        │ Semantic Analysis │
                        │ - type checking   │
                        │ - constraint scope│
                        │ - dependency order│
                        └────────┬─────────┘
                                 │ Validated AST
                   ┌─────────────┼─────────────┐
                   │             │              │
          ┌────────▼────┐ ┌─────▼──────┐       │
          │ TypeEmitter  │ │ParserEmitter│      │
          │ → Types.h    │ │→ Parser.h  │      │
          │              │ │→ Parser.cpp│      │
          └──────────────┘ └────────────┘      │
                                               │
                                    ┌──────────▼──────┐
                                    │  BBQContext.h    │
                                    │  (runtime lib,  │
                                    │   not generated) │
                                    └─────────────────┘
```

**Input:** A `.bbq` file containing format specifications.

**Output:** Three C++ files:
- `FormatTypes.h` — struct/union/enum definitions matching the BBQ types
- `FormatParser.h` / `FormatParser.cpp` — one parse function per rule
- User links against the shipped `BBQContext.h` runtime header

### Main Entry Point

```

Options:
  -o <dir>          Output directory (default: current directory)
  -frames <dir>     Frame file directory (default: ./backends/cpp/frames)
  -prefix <name>    Prefix for generated files (default: derived from input)
  -namespace <ns>   C++ namespace for generated code

  -trace <flags>    Debug output: A(ST) T(ypes) P(arser) S(ema)

  <prefix>Types.h       Type definitions
  <prefix>Parser.h      Parser declarations
  <prefix>Parser.cpp    Parser implementation
```

### Generation Pipeline

```
main(argc, argv)       [tools/bbqc.cpp]
  │
  ├─ Parse command-line arguments
  ├─ Read .bbq source file
  │
  ├─ Parser:  build AST (PEG recursive descent, generated by pegc)
  │
  ├─ Sema: validate AST
  │   ├─ Resolve @endian directive (AST keeps Default tag; emitters resolve)
  │   ├─ All rule references resolve to defined rules
  │   ├─ No circular rule dependencies (topological sort)
  │   ├─ Constraints reference only in-scope fields (forward ref checks)
  │   ├─ Interval expressions reference only previously-parsed fields
  │   ├─ Switch case values are unique, warn on missing default
  │   ├─ Compute expressions don't reference future fields
  │   ├─ Bitfield container is integer, widths sum to container bits
  │   └─ Element intervals only on counted arrays
  │
  ├─ TypeEmitter: generate Types.h
  │   ├─ Open Types.frame
  │   ├─ Emit forward declarations for all rules
  │   ├─ Emit struct/union/enum definitions (topologically sorted)
  │   └─ Close frame
  │
  ├─ ParserEmitter: generate Parser.h and Parser.cpp
  │   ├─ Open ParserHeader.frame and ParserImpl.frame
  │   ├─ Emit parse function declarations (one per rule)
  │   ├─ Emit parse function implementations
  │   └─ Close frames
  │
  └─ Report errors and exit
```

## C++ Parser Generation

For each BBQ rule, the ParserEmitter generates a parse function.

### Function Signature

```cpp
bool parse_RuleName(BBQContext& ctx, RuleName& out);
```

Every parse function returns `true` on success, `false` on failure. The `BBQContext`
manages position, intervals, error reporting, and backtracking.

### struct — sequential reads

```
Header = struct {
    magic:   uint32be where magic == 0x89504E47,
    version: uint16le,
    length:  uint32le where length > 0
}
```

```cpp
bool parse_Header(BBQContext& ctx, Header& out) {
    if (!ctx.read_uint32be(out.magic))
        return ctx.fail("Header.magic: expected uint32be");
    if (!(out.magic == 0x89504E47))
        return ctx.fail("Header.magic: constraint failed (magic == 0x89504E47)");

    if (!ctx.read_uint16le(out.version))
        return ctx.fail("Header.version: expected uint16le");

    if (!ctx.read_uint32le(out.length))
        return ctx.fail("Header.length: expected uint32le");
    if (!(out.length > 0))
        return ctx.fail("Header.length: constraint failed (length > 0)");

    return true;
}
```

### struct with intervals — scoped seeks

```
FileFormat = struct {
    header:  Header[0, 64],
    payload: Data[header.offset, header.offset + header.size],
    footer:  Footer[EOI - 16, EOI]
}
```

```cpp
bool parse_FileFormat(BBQContext& ctx, FileFormat& out) {
    {
        auto scope = ctx.push_interval(0, 64);
        if (!parse_Header(ctx, out.header))
            return ctx.fail("FileFormat.header");
    }
    {
        auto scope = ctx.push_interval(
            out.header.offset,
            out.header.offset + out.header.size);
        if (!parse_Data(ctx, out.payload))
            return ctx.fail("FileFormat.payload");
    }
    {
        auto scope = ctx.push_interval(ctx.total_size() - 16, ctx.total_size());
        if (!parse_Footer(ctx, out.footer))
            return ctx.fail("FileFormat.footer");
    }
    return true;
}
```

### union — backtracking try/restore

```
Message = union {
    text:   TextPayload,
    binary: BinaryPayload,
    error:  ErrorPayload
}
```

```cpp
bool parse_Message(BBQContext& ctx, Message& out) {
    {
        auto saved = ctx.save();
        auto& val = out.data.emplace<0>();
        if (parse_TextPayload(ctx, val))
            return true;
        ctx.restore(saved);
    }
    {
        auto saved = ctx.save();
        auto& val = out.data.emplace<1>();
        if (parse_BinaryPayload(ctx, val))
            return true;
        ctx.restore(saved);
    }
    {
        auto saved = ctx.save();
        auto& val = out.data.emplace<2>();
        if (parse_ErrorPayload(ctx, val))
            return true;
        ctx.restore(saved);
    }
    return ctx.fail("Message: no variant matched");
}
```

### switch — direct dispatch (no backtracking)

```
Payload = switch(header.type) {
    1: TextPayload;
    2: BinaryPayload;
    default: RawPayload;
}
```

```cpp
bool parse_Payload(BBQContext& ctx, Payload& out, int64_t discriminator) {
    switch (static_cast<int64_t>(discriminator)) {
    case 1: {
        auto& val = out.data.emplace<0>();
        return parse_TextPayload(ctx, val);
    }
    case 2: {
        auto& val = out.data.emplace<1>();
        return parse_BinaryPayload(ctx, val);
    }
    default: {
        auto& val = out.data.emplace<2>();
        return parse_RawPayload(ctx, val);
    }
    }
}
```

For string-typed switch discriminators, the signature uses `const std::string&`
and the body emits an if-else chain instead of a C++ `switch`.
```

### array (fixed count) — for loop

```
Colors = array<uint8>[3]
```

```cpp
bool parse_Colors(BBQContext& ctx, std::vector<uint8_t>& out) {
    uint32_t count = 3;
    out.resize(count);
    for (uint32_t i = 0; i < count; i++) {
        if (!ctx.read_uint8(out[i]))
            return ctx.fail("Colors[%u]", i);
    }
    return true;
}
```

### array (separator/terminator) — while loop

```
Records = array<Record>(Comma, Newline)
```

```cpp
bool parse_Records(BBQContext& ctx, std::vector<Record>& out) {
    out.clear();
    while (true) {
        // Check terminator first
        {
            auto saved = ctx.save();
            Newline term;
            if (parse_Newline(ctx, term)) break;
            ctx.restore(saved);
        }
        // Separator between elements (not before first)
        if (!out.empty()) {
            Comma sep;
            if (!parse_Comma(ctx, sep))
                return ctx.fail("Records: expected separator");
        }
        // Parse element
        out.emplace_back();
        if (!parse_Record(ctx, out.back())) {
            out.pop_back();
            return ctx.fail("Records: element parse failed");
        }
    }
    return true;
}
```

### array (until expression) — conditional loop

```
Packets = array<Packet>(none, until(remaining() < 4))
```

```cpp
bool parse_Packets(BBQContext& ctx, std::vector<Packet>& out) {
    out.clear();
    while (!(ctx.remaining() < 4)) {
        out.emplace_back();
        if (!parse_Packet(ctx, out.back())) {
            out.pop_back();
            return ctx.fail("Packets: element parse failed");
        }
    }
    return true;
}
```

### optional — try/restore with std::optional

```
MaybeExt = optional<ExtHeader>
```

```cpp
bool parse_MaybeExt(BBQContext& ctx, std::optional<ExtHeader>& out) {
    auto saved = ctx.save();
    ExtHeader tmp;
    if (parse_ExtHeader(ctx, tmp)) {
        out = std::move(tmp);
    } else {
        ctx.restore(saved);
        out = std::nullopt;
    }
    return true;  // optional always succeeds
}
```

### optional with constraint — predicated

```
OptData = optional<ExtraData> where flags & 0x01
```

```cpp
bool parse_OptData(BBQContext& ctx, std::optional<ExtraData>& out, uint8_t flags) {
    if (flags & 0x01) {
        ExtraData tmp;
        if (!parse_ExtraData(ctx, tmp))
            return ctx.fail("OptData: present but failed to parse");
        out = std::move(tmp);
    } else {
        out = std::nullopt;
    }
    return true;
}
```

### compute — inline expression

```
IPv4Header = struct {
    ver_ihl: uint8,
    ihl:     compute(ver_ihl & 0x0F : uint8),
    version: compute((ver_ihl >> 4) & 0x0F : uint8)
}
```

```cpp
bool parse_IPv4Header(BBQContext& ctx, IPv4Header& out) {
    if (!ctx.read_uint8(out.ver_ihl))
        return ctx.fail("IPv4Header.ver_ihl");

    out.ihl = out.ver_ihl & 0x0F;
    out.version = (out.ver_ihl >> 4) & 0x0F;

    return true;
}
```

### rule-level alternatives — unnamed biased choice

```
Number = uint8 | uint16le | uint32le
```

Alternatives use `std::variant`, same as union/switch:

```cpp
struct Number {
    std::variant<uint8_t, uint16_t, uint32_t> data;
};

bool parse_Number(BBQContext& ctx, Number& out) {
    { auto saved = ctx.save();
      auto& val = out.data.emplace<0>();
      if (ctx.read_uint8(val)) return true;
      ctx.restore(saved); }
    { auto saved = ctx.save();
      auto& val = out.data.emplace<1>();
      if (ctx.read_uint16le(val)) return true;
      ctx.restore(saved); }
    { auto saved = ctx.save();
      auto& val = out.data.emplace<2>();
      if (ctx.read_uint32le(val)) return true;
      ctx.restore(saved); }
    return ctx.fail("Number: no alternative matched");
}
```

### extern — user-provided parse function

```
# BBQ
Payload = extern("decompress_zlib", "std::vector<uint8_t>")
```

```cpp
// Generated type
using Payload = std::vector<uint8_t>;

// Generated parser
bool parse_Payload(BBQContext& ctx, std::vector<uint8_t>& out) {
    if (!decompress_zlib(ctx, out))
        return ctx.fail("Payload: read failed");
    return true;
}
```

Inline extern (as a struct field) works the same way — the extern function name
is called directly, and the C++ type string is used as the field type.

### bitfield — shift-mask extraction

```
# BBQ
Header = struct {
    flags: bitfield<uint16be> {
        version: 4,
        ihl: 4,
        dscp: 6,
        ecn: 2
    },
    total_length: uint16be
}
```

**Type:** inline bitfield becomes an anonymous struct; standalone rule becomes a
named struct. Each entry's C++ type is the smallest `uintN_t` that fits its width.

```cpp
struct Header {
    struct { uint8_t version; uint8_t ihl; uint8_t dscp; uint8_t ecn; } flags;
    uint16_t total_length;
};
```

**Parser:** reads the container, then shifts and masks each field. Big-endian
containers use MSB-first ordering (first entry at highest bits); little-endian
uses LSB-first (first entry at lowest bits).

```cpp
bool parse_Header(BBQContext& ctx, Header& out) {
    {
        uint16_t _bf;
        if (!ctx.read_uint16be(_bf))
            return ctx.fail("Header.flags: read failed");
        out.flags.version = static_cast<uint8_t>((_bf >> 12) & 0xF);
        out.flags.ihl     = static_cast<uint8_t>((_bf >> 8) & 0xF);
        out.flags.dscp    = static_cast<uint8_t>((_bf >> 2) & 0x3F);
        out.flags.ecn     = static_cast<uint8_t>(_bf & 0x3);
    }
    if (!ctx.read_uint16be(out.total_length))
        return ctx.fail("Header.total_length: read failed");
    return true;
}
```

### array with per-element intervals

```
# BBQ
entries: array<Entry>[num] @ [off + i * sz, off + (i + 1) * sz]
```

The `@ [start, end]` suffix on a counted array provides a per-element interval.
The loop variable `i` is available in the interval expressions.

```cpp
{
    auto count = static_cast<size_t>(out.num);
    out.entries.resize(count);
    for (size_t i = 0; i < count; i++) {
        auto elem_scope = ctx.push_interval(
            out.off + i * out.sz, out.off + (i + 1) * out.sz);
        if (!parse_Entry(ctx, out.entries[i]))
            return ctx.fail("...");
    }
}
```

### Expression compilation

BBQ expressions compile directly to C++ expressions:

| BBQ Expression | C++ Output |
|---|---|
| `header.length` | `out.header.length` |
| `entries[i].size` | `out.entries[i].size` |
| `length * 2 + 4` | `out.length * 2 + 4` |
| `flags & 0x0F` | `out.flags & 0x0F` |
| `a > 0 ? a : b` | `out.a > 0 ? out.a : out.b` |
| `crc32(data, len)` | `bbq::crc32(out.data, out.len)` |
| `EOI` | `ctx.total_size()` |
| `remaining` | `ctx.remaining()` |
| `pos` | `ctx.pos()` |
| `at_end` | `ctx.at_end()` |
| `i` | `i` (bare loop variable) |

Field references are prefixed with `out.` to access the parse result struct.
Function calls are prefixed with `bbq::` to call runtime-provided functions.
Built-in context properties (`remaining`, `pos`, `at_end`) map to `ctx.` methods.
The loop variable `i` is emitted as a bare identifier.

## BBQContext Runtime API

The runtime is a single header (~600 lines) that users include alongside the
generated code. It is NOT generated per-format.

```cpp
// BBQContext.h — BBQ Parser Runtime

#pragma once

#include <cstdint>
#include <cstddef>
#include <cstring>
#include <string>
#include <vector>
#include <span>

namespace bbq {

// ─── Checkpoint for save/restore backtracking ───

struct Checkpoint {
    size_t pos;
    size_t interval_depth;
};

// ─── Interval (byte range scope) ───

struct Interval {
    size_t start;
    size_t end;
};

// ─── RAII interval scope guard ───

class IntervalScope {
public:
    IntervalScope(class BBQContext& ctx, size_t start, size_t end);
    ~IntervalScope();
    IntervalScope(const IntervalScope&) = delete;
    IntervalScope& operator=(const IntervalScope&) = delete;
private:
    class BBQContext& ctx_;
};

// ─── Parse error info ───

struct ParseError {
    size_t pos;
    std::string message;
    std::string context;    // e.g. "Header.magic"
};

// ─── Main context ───

class BBQContext {
public:
    // Construction
    BBQContext(const uint8_t* data, size_t length);
    BBQContext(std::span<const uint8_t> data);

    // ── Position ──
    size_t pos() const;
    size_t remaining() const;
    size_t total_size() const;
    bool at_end() const;

    // ── Typed reads (advance position) ──
    bool read_uint8(uint8_t& out);
    bool read_uint16le(uint16_t& out);
    bool read_uint16be(uint16_t& out);
    bool read_uint32le(uint32_t& out);
    bool read_uint32be(uint32_t& out);
    bool read_uint64le(uint64_t& out);
    bool read_uint64be(uint64_t& out);
    bool read_int8(int8_t& out);
    bool read_int16le(int16_t& out);
    bool read_int16be(int16_t& out);
    bool read_int32le(int32_t& out);
    bool read_int32be(int32_t& out);
    bool read_int64le(int64_t& out);
    bool read_int64be(int64_t& out);
    bool read_float32le(float& out);
    bool read_float32be(float& out);
    bool read_float64le(double& out);
    bool read_float64be(double& out);
    bool read_bool(bool& out);
    bool read_bytes(std::vector<uint8_t>& out, size_t count);
    bool read_bytes(std::span<const uint8_t>& out, size_t count);  // zero-copy
    bool read_string(std::string& out, size_t count);
    bool read_string(std::string_view& out, size_t count);         // zero-copy

    // ── Interval management ──
    IntervalScope push_interval(size_t start, size_t end);

    // ── Save / restore (backtracking) ──
    Checkpoint save() const;
    void restore(const Checkpoint& cp);

    // ── Error reporting ──
    bool fail(const char* fmt, ...);
    const std::vector<ParseError>& errors() const;
    bool has_errors() const;
    std::string format_errors() const;

private:
    const uint8_t* data_;
    size_t length_;
    size_t pos_;

    // Interval stack
    static constexpr size_t MAX_INTERVAL_DEPTH = 64;
    Interval intervals_[MAX_INTERVAL_DEPTH];
    size_t interval_depth_;

    // Error accumulation
    std::vector<ParseError> errors_;
    std::string context_stack_;

    // Internal helpers
    bool bounds_check(size_t needed) const;
    size_t effective_end() const;
};

// ─── Built-in functions ───

uint32_t crc32(const uint8_t* data, size_t length);
uint32_t crc32(std::span<const uint8_t> data);
uint8_t checksum_xor(const uint8_t* data, size_t length);
size_t strlen(const std::string& s);
size_t strlen(std::string_view s);

} // namespace bbq
```

### Key implementation notes

**Endian reads** use compiler intrinsics for byte-swapping:
```cpp
bool BBQContext::read_uint32be(uint32_t& out) {
    if (!bounds_check(4)) return false;
    uint32_t raw;
    memcpy(&raw, data_ + pos_, 4);
    out = __builtin_bswap32(raw);  // or std::byteswap in C++23
    pos_ += 4;
    return true;
}
```

**IntervalScope** is RAII — entering an interval saves/sets the parse window,
leaving it restores:
```cpp
IntervalScope::IntervalScope(BBQContext& ctx, size_t start, size_t end)
    : ctx_(ctx) {
    ctx_.intervals_[ctx_.interval_depth_++] = {start, end};
    ctx_.pos_ = start;
}
IntervalScope::~IntervalScope() {
    ctx_.interval_depth_--;
}
```

**Save/restore** is just a position + interval depth snapshot — extremely cheap:
```cpp
Checkpoint BBQContext::save() const {
    return {pos_, interval_depth_};
}
void BBQContext::restore(const Checkpoint& cp) {
    pos_ = cp.pos;
    interval_depth_ = cp.interval_depth;
}
```

## Example Format Specifications

### PNG Header

```
@endian big

PNGSignature = struct {
    signature: bytes[8] where signature == "\x89PNG\r\n\x1a\n"
}

PNGChunk = struct {
    length: uint32,
    type:   bytes[4],
    data:   bytes[length],
    crc:    uint32 where crc == crc32(type ++ data, length + 4)
}

IHDRData = struct {
    width:              uint32 where width > 0,
    height:             uint32 where height > 0,
    bit_depth:          uint8,
    color_type:         uint8,
    compression_method: uint8 where compression_method == 0,
    filter_method:      uint8 where filter_method == 0,
    interlace_method:   uint8
}

PNGFile = struct {
    signature: PNGSignature,
    chunks:    array<PNGChunk>(none, until(type == "IEND"))
}
```

### IPv4 Packet

```
@endian big

IPv4Header = struct {
    ver_ihl:        uint8,
    version:        compute((ver_ihl >> 4) & 0x0F : uint8),
    ihl:            compute(ver_ihl & 0x0F : uint8),
    dscp_ecn:       uint8,
    total_length:   uint16,
    identification: uint16,
    flags_offset:   uint16,
    flags:          compute((flags_offset >> 13) & 0x07 : uint8),
    frag_offset:    compute(flags_offset & 0x1FFF : uint16),
    ttl:            uint8,
    protocol:       uint8,
    checksum:       uint16,
    src_addr:       uint32,
    dst_addr:       uint32,
    options:        bytes[ihl * 4 - 20] where ihl >= 5
}

IPv4Payload = switch(header.protocol) {
    6:  TCPSegment;
    17: UDPDatagram;
    1:  ICMPMessage;
    default: bytes[header.total_length - header.ihl * 4];
}

IPv4Packet = struct {
    header:  IPv4Header,
    payload: IPv4Payload
}
```

### TLV Protocol

```
@endian little

TLVEntry = struct {
    type:   uint8,
    length: uint16,
    value:  switch(type) {
        1: StringValue[length];
        2: IntValue[length];
        3: NestedTLV[length];
        default: bytes[length];
    }
}

StringValue = struct {
    text: string
}

IntValue = struct {
    value: uint32
}

NestedTLV = struct {
    entries: array<TLVEntry>(none, eof)
}

TLVStream = struct {
    entries: array<TLVEntry>(none, eof)
}
```

## Semantic Analysis

Validation performed on the AST before code generation:

1. **Rule resolution** — every RuleRef names a defined rule
2. **Duplicate detection** — no two rules share the same name
3. **Endian resolution** — `@endian` directive recorded; emitters resolve `Default`
4. **Cycle detection** — no circular rule dependencies (topological sort)
5. **Forward reference checks** — constraints, intervals, and compute expressions
   only reference fields that appear earlier in the same struct
6. **Switch validation** — duplicate case values rejected, warn if no default case
7. **Bitfield validation** — container must be integer, entry widths must sum to
   container bits, no duplicate entry names
8. **Element interval validation** — per-element intervals only on counted arrays
